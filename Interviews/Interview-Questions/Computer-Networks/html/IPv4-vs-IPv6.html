The Internet Protocol
Evolution

Think of an IP address as a digital home address. Just as every house needs a unique address to receive mail, every device needs a unique IP to receive data.

IPv4 (Internet Protocol version 4) is the legacy system we've used since the 80s. It's like a small town's postal system that ran out of numbers.

IPv6 (Internet Protocol version 6) is the modern upgrade. It's designed to ensure we never run out of addresses again—assigning a unique ID to every "grain of sand" on Earth if needed.

Header Structure Comparison

Notice how the IPv6 header is simpler despite being larger (40 bytes fixed vs 20+ bytes). It removes the Checksum (letting lower layers handle errors) and aligns fields to 64-bit boundaries for faster processing by modern routers.

IPv4 Header (Complex)

Checksum requires recalculation at every router hop (slow!).

IPv6 Header (Streamlined)

Fixed size (40B). No Checksum field. Flow Label helps QoS.

Interview Prep Guide

If asked by an interviewer, focus on these high-impact concepts. Click the cards to reveal the "Model Answer".

Why do we need IPv6 if we have NAT?

expand_more
Model Answer: While NAT (Network Address Translation) extended IPv4's life by allowing multiple private IPs to hide behind one public IP, it breaks the end-to-end principle of the internet. It complicates P2P connections (like VoIP or gaming) and adds latency. IPv6 restores unique public addresses for every device, removing the need for NAT entirely and simplifying routing tables.

What is the difference between Broadcast and Multicast?

expand_more
Model Answer: IPv4 uses Broadcast to send traffic to everyone on the subnet, which is inefficient and causes network noise (storms). IPv6 replaces this with Multicast (sending to a subscribed group) and Anycast (sending to the nearest receiver of a group). There is no Broadcast in IPv6.

How does IPv6 handle packet fragmentation?

expand_more
Model Answer: In IPv4, routers can fragment packets if they are too large (MTU issue), consuming CPU. In IPv6, routers do not fragment. If a packet is too big, the router drops it and sends an ICMPv6 "Packet Too Big" message back to the sender. The sender must perform Path MTU Discovery and fragment the data itself. This offloads work from the routers, making the network faster.

Explain "0::0" and "::1" notation.

expand_more
Model Answer: IPv6 uses "Zero Compression" (double colon `::`) to represent consecutive groups of zeros.
  • `::1` is the Loopback address (equivalent to 127.0.0.1 in IPv4).
  • `::` (all zeros) represents the unspecified address (used when a device doesn't have an IP yet).
