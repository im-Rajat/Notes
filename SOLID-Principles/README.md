# SOLID Principles

## Introduction

SOLID principles are important design principles in OOP languages like Java, Python, C++, etc.

### SOLID stands for:

[S = Single Responsibility Principle](https://im-rajat.github.io/Notes/SOLID-Principles/02_Single_Responsibility/)  
[O = Open/Closed Principle](https://im-rajat.github.io/Notes/SOLID-Principles/03_Open_Close/)  
[L = Liskov Substitution Principle](https://im-rajat.github.io/Notes/SOLID-Principles/04_Liskov_Substitution/)  
[I  = Interface Segregation Principle](https://im-rajat.github.io/Notes/SOLID-Principles/05_Interface_Segregation/)  
[D = Dependency Inversion Principle](https://im-rajat.github.io/Notes/SOLID-Principles/06_Dependency_Inversion/)
